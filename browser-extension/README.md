# 新加坡专线：纯浏览器插件

在 Edge 分身内使用受认证的 HTTPS 代理。**不安装 Windows 服务，不运行本地代理核心，不需要 Node、Python 或管理员权限。**

## 安装

1. 用你原来的 `--user-data-dir` 快捷方式打开 Edge 分身。关闭这个分身中此前打开的网页，完成安装后重启分身，清理旧连接。
2. 在**分身内**打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择本目录 `browser-extension`。Chrome 对应 `chrome://extensions`。
3. 将“新加坡专线”固定到工具栏。点击图标，展开“订阅设置”，粘贴你原来的 HTTPS 订阅链接，再点“保存并获取节点”。插件自动请求 `?target=browser`，不改变 v2rayN 使用的原链接。
4. 选择节点，点击“连接所选节点”。通过受认证代理完成出口检测后，网页才解锁。点击“断开并锁网”会阻止网页联网。

只在分身安装此插件。普通 Edge、其他浏览器和其他 Windows 程序不受插件设置影响。不要使用旧桌面启动器，它会禁用扩展；原来的 Edge 分身快捷方式即可。

## 操作

- **选择节点**：选中后点击连接才切换。当前服务器提供一个浏览器兼容入口；列表和切换支持订阅提供的多个 HTTPS 入口。
- **更新订阅**：连接期间通过现有代理更新；首次导入或离线更新时，只有插件自身的订阅请求临时直接连接。所有网页在整个过程保持锁定，失败后立即恢复锁定代理。
- **测速**：测试通过节点完成 HTTPS 请求的总耗时，显示毫秒；不是下载带宽。由于浏览器的代理配置按个人资料生效，测速会临时锁住网页，完成后恢复原连接。测试时也可以立即点击断开。
- **故障处理**：认证失败、证书过期、代理服务停止、网络异常均不会切回系统代理或直连。浏览器报告代理错误或健康检查失败后锁网，需重新连接。
- **更新插件**：拉取仓库更新后，在扩展管理页点击本插件的“重新加载”。不要删除后重新安装；升级后请重启分身并复测。

## 原理

```text
分身网页 ── 浏览器原生 HTTPS 代理 + 身份认证 ── 新加坡服务器 ── 国内/国外目标网站
```

插件使用 `chrome.proxy` 的单一固定 HTTPS 代理，没有 PAC、国内绕过列表或 DIRECT 回退。域名由服务器解析；插件禁用网络预测并限制 WebRTC 使用非代理 UDP，阻止不适合此代理的 WebTransport。HTTPS 网站内容仍由浏览器与目标网站建立端到端 TLS，代理不安装根证书、不解密这些网页。

声明式网络规则默认阻止所有 HTTP/HTTPS/WS/WSS 网页请求。只有节点通过 HTTPS 检测后，才添加明确包含顶层页面的允许规则。断开时先移除允许规则，再把代理指向无法连接的本机端口；默认阻止规则始终保留。插件自己的订阅和出口检测请求有单独的控制通道，不能被网页使用。

服务器提供独立的 `proxy-browser.service`，不会共享 v2rayN 或 Clash 的大陆分流规则。浏览器专用 JSON 使用每个启用订阅独立派生的认证凭据，关闭订阅会拒绝后续新连接。服务器拒绝连接本机、内网、云元数据及保留地址，并在校验 DNS 后连接确定的 IP，防止 DNS 重绑定。

## 必须注意的范围

- 保护范围是**插件正常启用时，此分身个人资料的网页请求**。禁用、卸载插件或在其他个人资料/无痕窗口访问，会移除或避开插件保护。无痕模式未开放。
- 不提供对整个 Edge 进程、更新器、外部应用、其他扩展的操作系统级网络封锁。终端 Claude Code、VS Code 扩展、桌面下载器不受此插件控制。不要在分身安装第二个代理扩展。
- 关闭代理后，已缓存的页面、Service Worker 离线内容仍可能显示；显示缓存不等于正在联网。已开始的下载/连接不能被所有扩展 API 可靠撤销，首次安装前应关闭旧页面并重启分身。
- 不修改 Windows 系统代理、路由表、网卡、Clash/v2rayN 配置。其他软件的系统代理/分流可以继续使用；全局 TUN 或透明代理仍可能接管浏览器到新加坡入口的底层连接，形成双重代理或影响速度。这是系统网络层行为，插件不能强制排除。
- 当前浏览器入口通过灰云域名直接连接服务器。TLS 加密保护通信内容，但不会隐藏服务器真实 IP，也不保证域名或 IP 不被封锁。
- 原订阅里的 Trojan + WebSocket + TLS／Cloudflare CDN 节点继续给原客户端使用；普通 Cloudflare 橙云不转发浏览器 HTTP CONNECT，不能把这些 CDN 地址直接改名当成 HTTPS 代理节点。
- 本地扩展存储包含订阅链接和代理认证信息，属于本地浏览器数据，不是密码保险箱。不要分享整个分身目录、订阅响应或含有私人链接的截图。仓库内不预置个人凭据。
- IP 检测工具、正常出口及锁网机制都不保证第三方服务账号安全。

服务端启用、证书续期、回滚和技术依据见 [浏览器代理部署文档](../docs/BROWSER_PROXY.md)。
