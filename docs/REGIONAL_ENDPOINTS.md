# 地区候选入口

面板「按地区挑选候选入口」的数据来自版本库中的 [`config/regional-endpoints.json`](../config/regional-endpoints.json)，不依赖某台服务器的 SQLite 数据库。新装、迁移和更新都会带上此列表。

## 使用

1. 在面板中选择「新加坡」或「菲律宾」，查看地址、原始备注、来源与验证说明。
2. 勾选需要的地址，或全选当前地区可添加的地址，点击「添加所选到编辑列表」。也可以复制本地区全部候选。
3. 添加只修改编辑框。它保留已有内容、顺序、备注和未保存的修改，并按地址去重（域名不区分大小写，省略端口与 `:443` 视为相同）。
4. 点击原有的「保存并更新订阅」，然后在客户端刷新订阅。未保存时不会改变生效中的节点。

新增地址追加在末尾；若设置了订阅节点数量上限，需要调大上限、设为 0，或自行将地址移到列表前面。已经在编辑列表里的地址不能重复勾选；删除地址后可以再次添加。

候选库不会自动加入默认优选列表或现有订阅。「恢复预置」仍然只恢复原来的通用默认列表，地区候选可以随时重新选择。

## 新加坡

完整保留用户提供的 3 个域名与 12 个 IP，包括原始备注。用户反馈这些入口在自己的网络上较快；本次未逐项独立复测，不能将其解释为所有地址均位于新加坡、属于 Cloudflare 或当前可用。部分 IP 不在 Cloudflare 公布的网段中，可能不能转发本项目的节点。

例如「Singapore官方」是用户原始备注，不代表项目核实了该网站的官方身份。

## 地区与速度的含义

[Cloudflare 官方说明](https://developers.cloudflare.com/support/troubleshooting/general-troubleshooting/geographic-traffic-routing/)：Anycast 地址会由多个机房同时宣告，路由可能不经过地理上最近的机房。可以用 `colo` 或 `cf-ray` 后缀查看一次请求的接入位置。

因此，菲律宾来源域名、MNL 的一次采样、服务器位于菲律宾，都不能保证用户设备连接时仍经过菲律宾。候选地址也可能解析到同一入口，不代表不同的独立线路。本次验证没有测量用户网络的吞吐量，也没有给出速度排名。请在实际使用代理的设备上进行延迟与下载测速；最终出口仍然是自己部署的服务器。

更新候选库时，请保留来源、日期、测试位置和验证范围，避免按 IP 归属地或域名后缀直接宣称「固定地区」或「最快」。
